# cbpi4-WhirlpoolStep

Плагин шага Whirlpool (Вирпул) для CraftBeerPi 4.

## Описание

Автоматизирует этап Whirlpool (вирпул/выдержка) в процессе пивоварения. Плагин позволяет:

- Установить целевую температуру для охлаждения сусла
- Задать время выдержки после достижения температуры
- Автоматически включить охлаждение при старте шага
- Автоматически отключить охлаждение при достижении целевой температуры
- Автоматически перейти к следующему шагу по окончании выдержки
